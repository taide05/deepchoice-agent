## 5. 优化链路（历史数据）

| 优化项 | 改动前 | 改动后 | 变化 | Commit |
|------|------|------|------|------|
| 两阶段仲裁（pro→flash+pro） | P50 162.6s / P95 410.3s | P50 130.5s / P95 164.2s | P95 -60% | `455e805` |
| 否定词→LLM 语义扫描 | 假阳性 100% | 假阳性 0% | -100pp | `455e805` |
| 检索器串行→asyncio.gather | 多 repo 逐个查 | 并发 | GitHub -50% | `ab952c4` |

> 注：100 case 实测的 P50=184s / P95=248s 比之前 50 case 单次 basline（P50=107s / P95=187s）偏高，原因是：①变体 case 查询更长（附加了 scene+constraint 描述）②部分 case 触发 flash→pro 仲裁 ③50 case 基线是初版仲裁（全 pro），数据点来源不同。
