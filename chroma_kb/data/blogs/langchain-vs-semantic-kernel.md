# LangChain vs Semantic Kernel

**Category**: AI/Agent Frameworks
**Expected winner**: Semantic Kernel

## Analysis

Semantic Kernel has first-class Azure/enterprise integration, built-in compliance filters, and native C# support which matters for enterprise .NET shops. LangChain is more flexible for Python-only stacks.

## Known Contradictions

### Language ecosystem
- Position A: LangChain's Python-first design is better for AI development
- Position B: Semantic Kernel's multi-language support (C#, Python, Java) matters for enterprise teams that aren't all Python
