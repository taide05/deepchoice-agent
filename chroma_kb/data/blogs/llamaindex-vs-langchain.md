# LlamaIndex vs LangChain

**Category**: AI/Agent Frameworks
**Expected winner**: LlamaIndex

## Analysis

LlamaIndex was purpose-built for RAG/data ingestion pipelines. LangChain is a general-purpose LLM framework. For pure RAG, LlamaIndex has better data connectors, indexing strategies, and retrieval abstractions. LangChain is better when RAG is one piece of a larger agent system.

## Known Contradictions

### Which is better for RAG
- Position A: LlamaIndex gives you RAG-specific abstractions out of the box
- Position B: LangChain's flexibility means you can build a more customized RAG pipeline
