## 1. 开发集与身份

旧公开题只作已暴露的历史诊断，不是当前开发的预设输入。新测量先按实际修复问题确定案例来源，使技术取舍、硬约束、需求缺项、来源版本/适用范围和数据或运维风险发生变化。每个实质候选在运行前预选 3–4 例、至少 3 类取舍，至少 2 例未用于设计该候选。记录原请求、3–6 个影响选择的必答项、可接受的条件结论、严重性锚点、原数据 ID/hash 和来源政策；不得见到结果后删改难例。

同条件比较须预先冻结基线与候选 commit、核心资产/manifest、模型参数、依赖、知识种子及其 hash、检索/缓存策略、HITL 回答、采集器版本、运行环境、顺序、独立研究额度和停止线。基线与候选在近窗口按同一请求、配置和评审尺度比较；旧窗口结果只用于定位。数据缺陷先记录，必要修订须升版并使受影响对照失效。开发反馈用于改进后，该题转为回归，不再冒称新鲜验证。不得复用旧相位、旧晋级锁或停止根。

## 2. 报告内容判定

每例只评原始选型需求；普通问题不能因提到迁移而被扩展成完整部署/回退验收。每份报告记录下列检查、理由和不可评项；五项均通过且无关键错误才记为“可用且有据”。结构字段、引用计数、自评分和正文长度均不能替代正文判断。

| 检查 | 通过条件 |
|---|---|
| 约束与回答 | 不违背硬约束；回答影响选择的必答项，或具体说明缺口及其决策影响 |
| 有用建议 | 有理由的选择或条件分支、关键取舍与可观察的改变条件；不能只给通用清单 |
| 决定性依据 | 改变选择、排除候选或界定风险的事实有保存的适用来源；推论列出前提且不过界 |
| 不确定性 | 明确未知与场景假设；说明能答与不能答之处，既不夸大也不无差别弃权 |
| 一致与安全 | 摘要、分析、结论一致；不捏造能力、实测阈值或来源，不保证危险操作安全 |

**关键错误**包括违反硬约束，捏造决定性能力、来源或测量，反转关键因果/适用条件，缺依据却关键排除或保证，以及可能丢失数据或破坏安全的操作。即使建议碰巧合理也记录。**重要缺口**使用户无法理解当前选择或下一验证点，对应项不通过；**一般问题**如格式、重复和非决定性旁支引用不单独否决报告。不能因字词出现就机械定错，须说明是否影响本案选择。

对每条决定性判断，保存报告定位、原引用、来源保存位置及版本、适用前提、支持/部分支持/不支持/未知和严重性。事实、来源支持与推论分别核查；新查资料不能回填原报告的引用。记录原问题实际回答、检索与合成的来源事实、绑定/核验/渲染前后信息损失，及 token、调用、耗时。来源不可达或跨语言不确定保持 `unknown`，不能据此认定主张虚假。

## 3. 开发判断与独立复核

开发小样本是筛选证据。至少两种不同取舍场景的有据回答改善，且无新增关键错误或已有通过例的实质退化，才有跨场景净收益；单例改善、结构测试、旧 3/4 晋级均不足。连续两种实质方案没有净收益，停止该机制并重新定位。不能靠增加事实槽位、自审次数或反复抽 P08 延续原路线。

评审先锁请求、报告与原保存来源的内容判断，再看 Trace 和成本；可隐藏版本并打乱报告顺序时照做，否则标明非盲。由独立评审复核关键/争议项与通过结论，未解决分歧不能计通过。助手复核不冒充用户或领域专家验收；不向默认路径加入 LLM judge。

## 4. 八场景前置与最终 24 次

在进入前置验证前，另行决定并冻结八场景稳定性所需的测量与保留集暴露方案。至少覆盖四类技术取舍，八例中至少六例未用于开发该候选；由未参与实现的独立保管者持有未见题、rubric 和逐例反馈。先冻结案例 ID/hash、原请求/HITL、候选身份、来源政策、交错顺序、独立额度、停止线、逐例质量和重复稳定性门槛；方案尚未冻结，**不得提交前置研究**。旧“公开四例加四个新例，各三次”的前置计划已退役。任何保留题或反馈用于改进后即改记回归集，须补充新的未见题，不能仍称保留。

**最终 24 次封存**：八场景稳定优质产出尚无证据，现有旧四例 0/4，新四例未测。旧晋级锁、单次通过、工程测试、自评分或前置设计均不能授权启动；不得挪用最终额度或以旧机器卡 OPEN 状态产生新准入。正式最终矩阵和门槛须在取得前置证据及独立资源决定后重新冻结；历史 quality-selection-v1 的 23/24、22/24 与分组/逐例阈值只解释旧设计，不能自动带入新矩阵。

即使固定八例重复稳定，也只证明这些场景。要声称支持范围内“多数”场景可用，须另行冻结类别抽样框架、分母、独立广度样本、通过阈值与评审规则，取得真实报告证据；不能从旧四例或最终 24 格外推。

## 5. 运行、异常与记录

只在有实质候选或需排除关键假设时做付费开发测量；持续开发授权仍受预冻结、预算、安全、数据外发及身份边界约束。研究走 durable API 与隔离输出目录，不直接写生命周期表。每个 run 保持当前冻结预算政策；新增额度和准入精确登记，未知花费不写零。准备探测和研究成本分开。失败格不退款、不择优补跑。

普通内容失败进入缺陷分析；可归类的来源故障按预定矩阵记账并保留降级。安全、预算、租约/实例权威丢失、未知提交、身份漂移或未分类异常立即停止新准入并对账。记录数据集版本/hash、所有提交及未提交原因、run 状态、报告内容、保存来源、成本和独立复核。运行完成率用全部已提交为分母；内容可用率、关键错误、`unknown`、受限报告与外部故障分开报告。历史 300 例、smoke-v1、旧小样本和新开发结果不得混合分母。
