# DeepChoice — AI 驱动的技术选型深度研究 Agent

DeepChoice 是基于 LangGraph 的单用户技术选型 Agent：输入需求与候选后，它从 6 路来源检索、比较并生成可查看和导出的选型报告。报告区分来源核验、模型推断与待补信息；重要决定需要核对关键依据和适用条件。
