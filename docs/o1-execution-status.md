## 两个已确认缺口

1. **运行种子准备错误。** 为符合旧复制helper的两项布局，准备时只复制了Chroma与
   learned_docs，将`chunks.json`和`seed-manifest.json`误归为构建附件。它们实际参与
   `_load_audited_index`和检索窗口审定：原根识别234个审定片段，准备根为0。语料字节相同
   没有保留完整运行行为；旧来源窗口/正文选段路径被关闭。本批含15个为P01/P04/P08审核
   的来源、234片段，但运行时未恢复其审定身份。此缺口不自动解释所有内容失败。
2. **合成纠正的预算预留不足。** 候选P01首次合成成功，保守预留40,601 tokens、实际结算
   10,415；后续总预算余量40,267。纠正再次发送完整提示加反馈，所需预留必高于40,601，
   因而在外呼前被拒绝。不是实际消耗达到60,000；终态已结算19,733，reserved/unknown为0。
   首答JSON和shape有效，但具体绑定错误未留存，不能归为某个句子编号错误。

静态合成提示从20,691增至22,327字符，候选本次来源也与基线不同；没有查出完全重复URL或
片段。应压缩无关示例/重复说明并保留完整依据及安全契约，验证一次纠正的预留余量；不提高
硬预算或将字节预留换成未经证明的乐观估算。种子准备修复必须核对审定索引和实际检索行为，
不能只核对Chroma文件相同。
