## 1. 产品目标与完成含义

面向单用户、可信网络、单实例/单 worker 的技术选型研究：用户给出需求与候选，得到能够回答
关键约束、解释取舍、追溯依据、诚实表达未知，并提供验证/迁移下一步的报告。
首要目标是在个人项目范围内，快速得到稳定、可用的报告并改善重点指标。
保留已实现的工程能力；不以增加企业平台、扩大来源数量或提高预算替代效果改进。
工作排序以报告是否帮助决策为中心：重大错误与关键需求覆盖、证据适用性和可行动性优先；
完成率、端到端耗时与 token 在同一批反馈中观察，不等所有质量缺口关闭才诊断效率。

分开记录四种结论：

1. **工程可运行**：测试、生命周期、安全、预算等契约通过。已有工程验收；不等于内容正确。
2. **局部优化有效**：冻结目标案例的前后配对支持一个具体改进。不能外推全部产品。
3. **当前产品范围验收**：最终候选在完整开发集与隔离保留集满足下述完成标准，独立 GPT-only
   盲评、固定锚点复核及残余风险记录齐全。只对冻结案例/产品范围负责，不声称普遍正确或经人工校准。
4. **12 路并发资格**：用户已在 2026-09-16 明确提出的目标。作为独立验收维度，测量已批准预先整合入 48 格路线；仍未完成，
   不作为单任务内容诊断的前置，也不自动删除。整体优化结项前需通过，或由用户明确接受后置。

## 5. 产品完成标准与停止条件

以下为本次地图提出的**目标验收卡**，不是已经通过的指标，也不覆盖历史 v4。
S0 在任何优化实现/新测量前完成严重性校准、评审手册和协议冻结；若修改这些目标，明确说明
用户价值与成本取舍，不按看到的候选得分事后降低门槛。

| 维度 | 最终候选必须满足 |
|---|---|
| 评估完整性 | 固定 12-case、2 次重复、24 个新 run 的终态/成本完整分类；24 份可评分普通或受限报告；开发与保留分别出结果，缺失不能从分母移除 |
| 决策与冲突 | 每个案例每次必答 rubric 无 0，决策分数至少 2/3；开发与保留各次 macro ≥80%；已冻结冲突点的 macro ≥75%，无捏造冲突；影响选择的关键约束项必须 2 分 |
| 严重错误 | 无已确认的重大事实/安全/数据损失错误，无未解决的重大争议；不允许平均分抵消。严重性定义在 S0 固定并独立复核 |
| 证据与表达 | 支撑推荐/否决/关键数字的决定性断言须有适用原始依据；无法确认时在该断言附近明确条件/未知，并不得依赖它给无条件结论。逐处支持和来源质量比例完整公布，不把 unknown 全判错或伪装正确 |
| 可行动性 | 每份报告说明选择条件、关键取舍、必要验证步骤及触发改变选择的条件；迁移/高风险操作须有验证和回退边界；受限报告明确指出缺口，不把受限报告自动判作质量失败或通过 |
| 工程与使用 | 最终代码相关与全套验证通过、需要的独立复审完成；默认 durable 提交→进度→HITL（适用时）→终态报告/导出可用；预算/安全/身份/恢复契约不退化 |
| 效率与成本 | 单 run 标准预算不变；全部终态保留费用/usage 已知与未知。效率不是无条件必须优化；声称改善须满足既定配对 ≥15% 且质量/完成率不降，无完整 usage 不声明 token 节省 |
| GPT-only 锚点复核与接受 | 2026-09-23 用户明确取消人工门禁；独立 GPT 先盲评预先固定的 2 份开发报告（含受限/争议样本），再与原判断对照，记录严重性、可用性、依据和残余限制；分歧扩查相关类别。最终报告明确标为 GPT-only，不称人类校准或人类接受 |

数字阈值是面向本产品的预设验收目标；按用户新决定采用 GPT-only 复核，仍不声称统计显著、行业标准或人工校准。
局部 S1 测量仍沿用：2 目标案例 + 1 回归案例、两版各 2 次；目标两次均改善，回归不新增
重大错误且决策/引用/完成率不降。只能证明所选案例局部改善，S3 再检查最终产品范围。
S3 只有候选样本，不能据其声称相对 baseline 的保留集非退化或全产品改善；这类因果比较须
另有同窗口 baseline 对照。固定开发锚点的独立 GPT 复核已完成；最终盲评、重大争议复核和残余风险记录未完成前最多称“助手评审下暂定验收”。

停止不等于通过：

- **成功停止**：S3 全部完成标准满足，S4 记录齐全；C1 通过或被用户明确后置。
  E1 有诊断/处理结论即可，不强求一定节省；X1 未做不阻止结束。
- **证据停止**：没有可修复的高优先问题，或一个假设验证不支持收益，记录结果并重排；不追加同类采样直到通过。
- **目标复议**：最多 3 个方向尝试后仍达不到标准，或两次连续付费停止但未获得有效配对，提交范围/可行性结论；不能自动继续追加周期。
- **硬边界停止**：安全、预算、租约、身份、主机或未分类异常按冻结协议停止新准入；收尾后继续可做的离线归因，不把整个工作交回用户只说“是否继续”。
- **资源/额度边界**：保留最终验收预算。助手额度中断只做可恢复交接；不能把研究预算上限解释为无限。
