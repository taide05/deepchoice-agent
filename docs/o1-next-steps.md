# O1 剩余任务卡

更新：2026-09-17。顺序 A → B → C → D → E，不自动进入 O2。
本轮仅 O1-A 获授权；B～E 是建议下一步，付费授权和批次解禁须分别确认。

| 卡 | 要做什么 | 验收 / 停止线 |
|---|---|---|
| O1-A 收口评估口径（已完成） | v4 协议；六份开发报告逐处原子台账；历史/新候选/未来配对分母分开；评审资格和 O1 结项状态 | 离线复算与身份校验、争议独立复核记录通过；20 聚焦 / 1196 全套通过；无新研究、无保留集泄露 |
| O1-B 离线补齐单 case 资格 | 严格 JSON/schema 与修复次数/finish_reason 观测；区分解析失败、截断、预算、来源限流/超时、lease/recovery；冷启/heartbeat 故障复现 | 不改质量 Prompt 或扩大硬预算；最小回归及全套通过；生命周期/并发改动独立复审及契约文档同步；无法复现的风险保留 unknown |
| O1-C 逐次冷启单例 | 在 B 验收、主机/API 前置就绪并单独授权后，建议先 P01；新实验数据库对、同知识快照；健康/探测、缓存拆账、冷启和六源控制观察 | 只提交明确批准的一例，不自动排队；失败/降级停止；是否增加一次重复另确认。剩余 5 不是许可 |
| O1-D 新候选正式串并发配对 | 单例资格达标后重新批准批次与新额度；先 12 serial + 12 concurrent，第一轮通过/无阻断再单独批准第二轮 | 同锁定身份、完整报告/评分/复核；出现异常停后续准入，不自动补跑；两次均通过才能宣布并发 gate 通过 |
| O1-E 评估闭环与假设冻结 | 盲评资格下独立核验锁定候选，保留集隔离且只回聚合；全体成本/失败/风险汇总；选一个主要优化假设 | 分清 O1 闭环、不通过、unavailable 和并发通过；助手未人类校准必须注明；未获新授权不实施 O2 |
