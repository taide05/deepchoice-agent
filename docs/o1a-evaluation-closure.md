  [WAL 官方文档](https://www.sqlite.org/wal.html)、[备份官方文档](https://www.sqlite.org/backup.html)。

  [Bun Node-API](https://bun.sh/docs/runtime/node-api)。
- uv.lock 是 uv 专用格式；不能从 pyproject 的 PEP 元数据兼容推导其锁文件符合该标准。
  [uv 文件结构](https://docs.astral.sh/uv/concepts/projects/layout/)。

## 复算与验证

无网络/模型/服务，默认仅读已提交台账与历史绑定；verify-local 仅读六个明确路径，
核对 report/snapshot SHA256 和引用在原行出现，不枚举实验目录或读取保留集：

```powershell
.\.venv\Scripts\python.exe -m benchmarks.o1_claim_review
.\.venv\Scripts\python.exe -m benchmarks.o1_claim_review --verify-local
.\.venv\Scripts\python.exe -m pytest tests/test_o1_claim_review.py -q -p no:cacheprovider
```

检查器验证身份、逐处顺序、引用别名、行/atom 数及判断枚举，统计 micro/macro；
不自动判断语义、证明分母分类绝对正确或替代独立评审。置信度/成熟度等推论同样不得漏项。
